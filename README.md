# backmeupplz/tap

Homebrew formulae for [plain](https://getplain.org), which compiles, tests, deploys, verifies and upgrades EVM smart contracts:

```sh
brew install backmeupplz/tap/plain
```

The release workflow of [backmeupplz/plain](https://github.com/backmeupplz/plain) rewrites `Formula/plain.rb` for every release, with the sha256 of each release tarball.
